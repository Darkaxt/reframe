# ClaudeGPT Reframe 0.11.0-claudegpt.38

- **CPU, GPU and RAM per thread.** Each session's tile header shows what the thread uses now, with small chip,
  graphics-card and memory icons as the Taskbar Thermals widget draws them: CPU and GPU in percent of the machine,
  RAM as its private memory. It counts the session's claude and everything it started (tool shells, builds,
  servers), also once the process that started them ended. CPU and GPU turn orange from 50% and red from 85%. The
  tooltip lists the busiest processes (name, pid, CPU, GPU, memory). Updated every 3 s while a window is shown.
  Sessions still running in an older PTY host (kept across an update) show no meters until they are restarted.
- **Every session runs in a job object.** To count what a session started, its process starts in a Windows job of
  its own. The job ends nothing when closed, and processes that ask to leave it (as gated launchers do) still can.
  The per-process list is the base for the planned warnings menu (runaway processes).

The PTY host protocol gains the additive `monitor` service (`monitor.sample`; the Rust host only, observers may ask
it). The profile and `state.json` are unchanged.
