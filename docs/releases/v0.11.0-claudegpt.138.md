# 0.11.0-claudegpt.138

More stack samples of the shell's unresponsive moments.

- After .136 started, the UI thread stalled for 1 to 11 seconds at a time during its first minute, about half of that time busy, in work no label names. Only the first of those stalls was sampled, because a stall's first stack was taken at most once in ten minutes.
- A stall's first stack is now taken at most once in 30 seconds, so a run of stalls is sampled throughout.
- The list of terminal and graphics threads is long and changes little, so it is still logged at most once in ten minutes.
