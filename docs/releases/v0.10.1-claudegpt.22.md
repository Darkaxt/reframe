# ClaudeGPT Reframe 0.10.1-claudegpt.22

- The PTY host now works out what each session is doing (starting, idle, busy, waiting for you, ended) from Claude
  Code's hooks and its session registry, and tells Reframe when Claude is done or needs you (new `sessions`
  service, added to the host protocol without changing its version). Reframe still decides how a notification is
  worded and whether it is shown, and how an exit counts. A session that finished or asked something while no
  Reframe was attached (during an update) shows its current status, and its notification, when Reframe attaches.
  - The Rust host follows the sessions with a new library (`rust/reframe-sessions`), WSL sessions included; the
    Node host does the same with Reframe's own code. Both are held to Reframe's in-process status in tests.
  - Sessions started by an older Reframe, or on a host from one (taken over in an update), are followed by Reframe
    itself, as before; a session is never followed in both places, so nothing is announced twice.
- The Codex quota read gives up after 20 seconds also when LLM Coordinator closed its output but did not exit,
  and ends it then, as Reframe's own read does.

Windows x64 portable release; unsigned.
