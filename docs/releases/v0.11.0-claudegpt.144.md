# 0.11.0-claudegpt.144

The session list starts collapsed, like folders in a file explorer, and builds rows only for what is open.

- Projects no longer open by themselves when one of their threads is running. A closed project's header still shows how many chats it has and how many are running; its chat rows are built only when you open it.
- A thread's subagents are hidden by default, even while some of them run. Its "N agents · M ended" chip still shows the counts; click it to list them.
- The archived chats' rows are built only while that list is open.
