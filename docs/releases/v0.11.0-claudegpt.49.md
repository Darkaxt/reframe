# ClaudeGPT Reframe 0.11.0-claudegpt.49

- **Messages to running threads.** The top bar has four new buttons before the warnings:
  - **Pause** asks threads that are at work (busy, or with a command in the background) to reach a safe pause point, save their work, stop anything that would take more than 5 minutes, and wait.
  - **Continue** goes only to the threads paused from here that are idle now.
  - **Clean up** asks threads to delete the old and superseded files their projects own. Deletions that need elevated rights become an input request instead of being skipped. Then the threads go back to their plan.
  - **Message** sends a text of your own.

  Each button shows how many threads the message would reach and asks before sending. A busy thread gets Ctrl+B first, so a long command moves to the background and the message is read at the next turn. Threads waiting on a question or still starting are left alone. The **All / This** toggle beside the buttons narrows the messages to the thread the window shows, or the tile focused last.
- **Identity of threads taken over or found outside.** Claudes running in another terminal show the provider they were started with, read from their command line, in the session list. A Reframe thread resumed in another terminal and continued here takes that terminal's provider, model, effort and permission mode. A conversation found again on disk gets its provider from the model of its last reply (claude-* is Anthropic).

The profile and `state.json` format are unchanged.
