# 0.11.0-claudegpt.119

## Gemini threads

- A third provider, Gemini: Google's models (Gemini 4 Neon, Hydrogen, Carbon, 3.8 Flash) through the ClaudeGPT proxy,
  which needs its own Antigravity sign-in. A Gemini thread is a ChatGPT-route thread (the same Claude Code install,
  workspace and browser setting) that always names a Gemini model: Gemini 4 Neon until another is set in Settings'
  "New Gemini threads".
- Everywhere a provider is chosen or shown: New session, Change model, the list's Model provider menu, Settings'
  defaults and profiles, the session list, tiles and Overview (a blue spark).
- `open_thread` takes `provider: gemini`; messages between threads name a Gemini thread "Gemini (Google)".
- The proxy's running-thread count includes Gemini threads.
