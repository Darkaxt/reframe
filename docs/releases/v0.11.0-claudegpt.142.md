# 0.11.0-claudegpt.142

The session list no longer freezes the window to update a background thread's text.

- The "Background: … · 14 min" line under a background thread's row and its status mark's tooltip are now updated in place every 20 seconds, instead of rebuilding the whole session list each time the minutes change. This removes a pause of about a second that happened several times a minute while a thread had background work.
- The list of Claude Code sessions running outside Reframe is now read off the UI thread on each 5-second refresh, so a slow disk or many running sessions no longer stall the window.
