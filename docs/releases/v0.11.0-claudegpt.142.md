# 0.11.0-claudegpt.142

The session list no longer freezes the window to update a background thread's text.

- The "Background: … · 14 min" line under a background thread's row and its status mark's tooltip are now updated in place every 20 seconds, instead of rebuilding the whole session list each time the minutes change. This removes a pause of about a second that happened several times a minute while a thread had background work.
- The session list no longer re-reads every Claude Code session every 5 seconds. It follows changes as they happen: a Claude Code session started, renamed or ended in another terminal appears, changes or disappears within a moment, and nothing is read while nothing changes.
- The list is no longer rebuilt on a timer. Only the "5m" / "2h" times next to each chat are updated, every 30 seconds, and only the rows whose time actually changes are redrawn.
- When the list does change, only the rows that changed are rebuilt; the other rows stay as they are.
