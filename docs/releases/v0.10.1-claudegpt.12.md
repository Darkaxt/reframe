# ClaudeGPT Reframe 0.10.1-claudegpt.12

- Reframe now deploys the patched Claude client itself. At every managed start (and whenever the client pipeline
  runs `adopt-client.ps1`), the newest client the pipeline qualified is copied, never patched, to
  `clients\<provider>\<version>-<sha12>\claude.exe` for both the Anthropic and the ChatGPT route, and
  `client-adoption.json` records it. A client is adopted only when its verification record says it is qualified,
  its executable, verification and manifest hashes match, it is newer than the current one and it is not flagged
  `configFormatChanged`.
  - New sessions of both providers start on the newest adopted client (each new session re-reads the record and
    checks the hash); running sessions keep the executable they started from. No idle boundary is needed.
  - The ChatGPT route no longer runs the in-place `~\.local\bin\claude.exe`.
  - Client copies that are neither current nor the executable of a running process are deleted at adoption and at
    every managed start.
- From upstream 0.10.1: pasting an image on Windows no longer takes seconds.

Windows x64 portable release; unsigned.
