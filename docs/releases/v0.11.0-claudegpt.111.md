# 0.11.0-claudegpt.111

The session list width and the Chat view are kept.

- **Session list width.** The width you drag the list to is saved (`preferences.sidebarWidth`, 180-600) and every window starts with it.
- **Chat view for all threads, kept.** The Chat / Terminal button is one choice for every thread in every window (`preferences.chatView`): switching it switches the open tiles, a thread you open later comes up the same way, and a restart keeps it.
- Tests: `ViewPreferenceTests` (round trip, an out-of-range width dropped).
