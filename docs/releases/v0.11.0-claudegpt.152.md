# 0.11.0-claudegpt.152

- `message_thread` to a name several threads share no longer fails with "more than one thread is named …". Every thread of that name gets the message, only the running ones if any of them runs, and the sender is told which got it (id, provider, running or ended).
- `message_thread` takes an optional `provider` (openai, claude or gemini) to reach only the thread of that name on those models. The id in brackets after the name (`Warhammer Survivors [0e0e25]`) still picks one. Threads started under an older host don't have `provider` yet, but the delivery to every match works for them too, since it lives in the shell.
