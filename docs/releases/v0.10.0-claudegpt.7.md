# ClaudeGPT Reframe 0.10.0-claudegpt.7

Fix: a chat whose Claude CLI never wrote any history (for example one closed
before its first message) could not be deleted: the history helper refused it
with "Claude session must resolve to one exact project history". Delete now
removes only Reframe's entry for such a chat, after the same confirmation (which
says so), and rechecks right before the change that no history appeared. Archive
reports that there is nothing to archive. Chats with history are unchanged: they
still go through the exact-file helper.

Deployment: a Reframe running from another folder (a second installation, a
development build or a test fixture) no longer counts as this installation's
app when an activation, restore or maintenance stop checks for idle clients.
Windows x64 portable release; unsigned.
