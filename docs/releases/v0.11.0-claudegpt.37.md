# ClaudeGPT Reframe 0.11.0-claudegpt.37

- **Take Over exclusions.** The popup that offers to take over a terminal window dropped on Reframe has a new
  "Create exclusion" button. The picked sessions are not offered again when their terminal is dropped here. They can
  still be taken over on purpose with the new "Take over…" item in their list entry's context menu. Settings lists
  the exclusions under "Take over exclusions", where each one (or all) can be removed.
- **Archive and delete in a popup.** Archiving or deleting chats (one, or the selected ones) no longer happens out of
  sight: a popup shows the check, asks the question (in place of the native message box), shows the archiving or
  deleting with the seconds so far, then each chat's outcome. "Run in background" closes it while the work goes on;
  the outcome then appears in the result strip under the toolbar.
- **Quota diagnostics.** When the Codex/Claude quota cannot be read, `logs\main.log` now says why (no answer in time,
  the Coordinator's exit code and error output, or output that is not JSON), to find why the quota panel stays hidden.

The PTY host protocol and the profile are unchanged (`quota.codex` may add an `error` text next to a null `usage`). `state.json` gains an optional `takeoverExclusions` list; older
versions ignore it.
