# ClaudeGPT Reframe 0.11.0-claudegpt.37

- **Take Over exclusions.** The popup that offers to take over a terminal window dropped on Reframe has a new
  "Create exclusion" button. The picked sessions are not offered again when their terminal is dropped here. They can
  still be taken over on purpose with the new "Take over…" item in their list entry's context menu. Settings lists
  the exclusions under "Take over exclusions", where each one (or all) can be removed.

The PTY host protocol and the profile are unchanged. `state.json` gains an optional `takeoverExclusions` list; older
versions ignore it.
