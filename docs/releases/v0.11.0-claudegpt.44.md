# ClaudeGPT Reframe 0.11.0-claudegpt.44

- **Threads know which model they are talking to.** A message one of reframe's threads sends another thread
  (Claude Code's SendMessage) now starts with a tag naming the provider and the exact model the sending thread runs
  on, such as `[from a Reframe thread on OpenAI, model gpt-6.1-sol]` or
  `[from a Reframe thread on Claude (Anthropic), model claude-opus-5-5]`. The PTY host adds it through a hook of the
  session's settings (the model is the one the session's transcript last answered with), so it does not depend on
  the model remembering to say it. The call still goes through Claude Code's permissions as before. Threads started
  or resumed under this release's host have it; WSL sessions do not.

The PTY host's `launch` service is version 4 (the message tag); the profile and `state.json` are unchanged.
