# 0.11.0-claudegpt.147

Messages between threads (wake_thread) and scheduled task runs now reach the thread even when they are long.

- Reframe types a message into an idle thread as a paste followed by Enter. When the message was long (about 3.5 KB and up) and the receiving session was large, Claude Code was still reading the paste when Enter arrived, so the Enter was lost and the message was never sent, while main.log said "delivered".
- Reframe now waits for the thread to show that it took the prompt (it turns busy), and presses Enter again, up to four times five seconds apart, while it has not. A message that is still not taken is reported as not delivered, with a notification, instead of "delivered", and main.log says so.
