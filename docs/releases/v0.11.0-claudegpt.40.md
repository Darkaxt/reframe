# ClaudeGPT Reframe 0.11.0-claudegpt.40

- **Runaway process warnings.** The Rust PTY host now watches what each thread starts (through the session's job, so
  nothing needs wrapping or gating) and raises a warning when a process the thread started keeps at least 0.8 of a
  core busy for 10 minutes, when a search tool (grep, rg, find, findstr, where...) has been searching a whole disk
  for 2 minutes, or when processes are still running a minute after the thread ended. The top bar gets a warnings
  button (right side, before Settings) with a count; its dropdown lists each warning with its thread, process and
  command line, and offers **Notify thread** (types a short note into the thread for its agent, while the thread
  waits for input), **Kill process** (ends the process and what it started, while the thread is idle, waiting or
  ended) and **Dismiss**. Warnings clear themselves once the process is gone.

The PTY host protocol gains additive `monitor` methods and events (`monitor.warnings`, `monitor.kill`, the
`warning` and `cleared` events; `monitor` is now version 2), documented in `docs/ptyhost-protocol.md`. The profile
and `state.json` are unchanged.
