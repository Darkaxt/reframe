# ClaudeGPT Reframe 0.10.1-claudegpt.21

- The PTY host now also asks LLM Coordinator for the Codex quota, checks whether your Claude Code settings have a
  status line, and verifies the adopted Claude clients by hash (new `quota`, `clients` and `launch` services, added
  to the host protocol without changing its version). Reframe asks for the quota as often as before; the host keeps
  the clients' hashes across Reframe restarts and updates, so a large client is not hashed again after one.
  - The Rust host reads them with a new library (`rust/reframe-services`); the Node host serves the same with
    Reframe's own code. Both give the same answers.
  - A host from an older Reframe (taken over in an update) does not offer them, and a request that fails is not
    lost: Reframe then reads for itself, as before. The launch config next to a directly started reframe.exe is
    still read by Reframe itself, since it decides which host is used.

Windows x64 portable release; unsigned.
