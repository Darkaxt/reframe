# 0.11.0-claudegpt.135

The shell stays responsive while terminals are busy.

- Each terminal's output now reaches the window in batches: output that arrives while one batch waits for the UI thread joins it. Previously every chunk had its own dispatch. After a restart, when every thread replays at once, that queued thousands of them (2,910 in one 77-second freeze), and each also scrolled its terminal and raised accessibility events.
- Terminal output, snapshots and exits now run below input priority, so keys and clicks are handled first.
- The UI watchdog no longer re-posts the dispatcher's queue message: its data showed no message was being lost.
