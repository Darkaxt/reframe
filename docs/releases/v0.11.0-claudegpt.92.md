# 0.11.0-claudegpt.92

- A thread opened with `open_thread` no longer fails unseen. For three minutes after it opens, Reframe reads its transcript; if the first answer is an API error (for example "400 Unknown model"), the opener gets a message with the error and what to change (an explicit `model`), and you get a notification. Nothing the thread was asked has run in that case.
- `open_thread`'s `model` description tells the caller to name an OpenAI model explicitly, since the saved default can be outdated.
