# 0.11.0-claudegpt.143

The window no longer stalls repeatedly during the first minute after Reframe starts.

- When Reframe connects to its sessions, each session reports its status. The session list is now redrawn once after that burst of statuses instead of once per session.
- A project's row in the session list is kept as it is when nothing about it changed, instead of being rebuilt with every list update. Only changed rows are rebuilt.
- The Claude and Codex quota rows are no longer rebuilt each time a Claude session reports its status line; they are rebuilt only when a percentage or reset time actually changes.
- main.log now records how long each session list update takes and how many rows were rebuilt or kept (during the first two minutes, later only slow updates), how long each terminal tile takes to build at start, and, once a minute after start, how many elements each window holds.
