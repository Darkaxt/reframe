# 0.11.0-claudegpt.136

Native stacks for the shell's unresponsive moments.

- The UI watchdog's stack samples now include native frames (module and offset) as well as managed ones (type and method), read with DbgHelp from the same process snapshot. When the UI thread waits inside native code, such as the message pump, the samples show where.
- Each sample also lists the threads that are inside the terminals' or graphics modules (terminal control, Direct3D, DXGI, the GPU driver, WPF's renderer, text input). Identical stacks are counted once.
- A stall's first sample is taken at 1.8 seconds, so that shorter stalls are caught too, and the next ones at 5, 10 and 20 seconds. The first sample is still taken at most once in ten minutes.
