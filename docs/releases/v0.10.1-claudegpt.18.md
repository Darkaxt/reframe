# ClaudeGPT Reframe 0.10.1-claudegpt.18

- A PTY host written in Rust (`reframe-host.exe`), the first step of moving Reframe to Rust. It speaks the same
  protocol as the Node host (docs/ptyhost-protocol.md) and is opt-in: set `REFRAME_PTYHOST=rust` before starting
  Reframe. Without it nothing changes; the Node host stays the default.
  - Sessions already running in a host of the other kind keep running there (they are left out of this Reframe) and
    new sessions go to the configured host.
  - The installed Rust host is copied to its own versioned runtime folder, as the Node host is.
  - Known differences of its terminal mirror (what a window repaints from when it opens): no strikethrough, blink,
    invisible or overline attributes, and in the alternate screen only that screen is restored.
- One conformance suite (`npm run test:conformance`) checks both hosts against the protocol; CI builds, lints and
  tests the Rust code and ships the release build with the app.

Windows x64 portable release; unsigned.
