# ClaudeGPT Reframe 0.11.0-claudegpt.45

- **A thread can open another thread, on OpenAI or Claude.** Reframe's threads get a tool of the PTY host's,
  `open_thread` (an MCP server the host runs for each session): given a name and a first prompt (and optionally the
  provider, OpenAI by default, a folder and a model), reframe opens that thread as its New session dialog would, with
  the provider's remembered choices, in a tile of the window showing the thread that asked, where the user sees it and
  can take it over. Its first prompt starts with a line naming the thread that opened it, so the two talk with
  SendMessage (whose messages carry each side's provider and model since .44). So a Claude thread can hand work to an
  OpenAI model and get its answers back. A request made while no reframe window is attached is dropped, not opened
  later. Threads started or resumed under this release's host have the tool; WSL sessions do not.

The PTY host's `launch` service is version 5 (the thread tools); the profile and `state.json` are unchanged.
