# 0.11.0-claudegpt.150

Messages no longer wait for a thread to become idle.

- wake_thread messages, handed-off jobs and scheduled task runs used to wait until the thread was idle. Most threads are rarely idle: they work, or run background commands and monitors. So a message could wait for hours, and was given up after 12. Such a message is now typed in at once, and Claude Code queues it for the thread's next step, as when you type while it works. It still waits while you are in that thread's tile or writing in it, while the thread asks a permission or a question (typing would answer it), and for a busy Gemini thread.
