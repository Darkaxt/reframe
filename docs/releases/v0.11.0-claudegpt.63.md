# ClaudeGPT Reframe 0.11.0-claudegpt.63

- **The ChatGPT proxy is watched.** When the Claude settings name a proxy on this machine (the loopback address in `env.ANTHROPIC_BASE_URL`, the only key read), Reframe asks its `/healthz` every 30 seconds. The foot of the session list shows "Proxy online" or, in red, "Proxy offline" (the tooltip has the address and the time of the last check). When it stops answering twice in a row while a ChatGPT thread runs, a toast says so, and another when it is back. Each change is also logged as a `proxy:` line. Reframe only observes it; the proxy is neither started nor changed. Nothing is shown when the settings name no local proxy.
