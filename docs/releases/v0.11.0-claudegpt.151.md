# 0.11.0-claudegpt.151

Threads message each other with message_thread, and a message no longer starts an ended thread.

- message_thread replaces wake_thread as the way for a thread to give another thread a message. A running thread gets it as before.
- An ended thread is no longer started just to get a message. The message is kept and given to it when it next starts, whether you resume it, a task runs in it or another thread wakes it, and the sender is told so. Send it with wake: true to start the thread now. A message kept 14 days without the thread starting is dropped, and the sender is told.
- wake_thread still works and still starts an ended thread, for older threads and saved notes that use it.
