# ClaudeGPT Reframe 0.11.0-claudegpt.41

- **Warnings history.** The top bar's warnings dropdown now keeps track of earlier warnings: those that resolved by
  themselves, were killed (with how many processes) or were dismissed are listed under "Earlier", newest first,
  with when that happened (the last 50, while Reframe runs). "Clear" forgets them. The warnings button stays in the
  top bar once there was a warning; it shows the count of open ones, and turns grey when none is open.

The PTY host protocol, the profile and `state.json` are unchanged.
