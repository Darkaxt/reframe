# ClaudeGPT Reframe 0.11.0-claudegpt.67

- **A thread can shut down the threads it opened: the new `close_thread` tool.** `close_thread(name, action)` ends another thread by name (action `end`, the default: its session stops, its tile closes, and it stays listed as ended, so `wake_thread` or Resume brings it back) or archives it (action `archive`: it is ended, then archived to a verified ZIP exactly as the list's Archive does, after the user confirms in Reframe's window). A thread cannot close the thread it runs in; an unknown or ambiguous name is told back to the asker. Nothing is deleted.
