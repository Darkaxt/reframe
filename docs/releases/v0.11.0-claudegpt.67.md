# ClaudeGPT Reframe 0.11.0-claudegpt.67

- **A thread can shut down the threads it opened: the new `close_thread` tool.** `close_thread(name, action)` ends another thread by name (action `end`, the default: its session stops, its tile closes, and it stays listed as ended, so `wake_thread` or Resume brings it back) or archives or deletes it (actions `archive` and `delete`: it is ended, then archived to a verified ZIP or deleted exactly as the list's Archive and Delete do). A thread cannot close the thread it runs in; an unknown or ambiguous name is told back to the asker. Each thread now records which thread opened it (`openedBy` in its state entry). A thread may also `delete` the threads it opened itself, and ending, archiving or deleting those happens at once; archiving a thread it did not open still asks the user in Reframe's window first, and deleting one it did not open is refused.
