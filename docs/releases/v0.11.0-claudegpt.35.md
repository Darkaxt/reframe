# ClaudeGPT Reframe 0.11.0-claudegpt.35

- **Sessions of an earlier terminal host keep running beside the new one.** A terminal host kept running across the
  update (so that its sessions went on) can be from before the native shell, and cannot start sessions for it: new and
  resumed sessions failed with "Claude Code could not be started", and 0.11.0-claudegpt.34 offered to restart it, which
  ended its sessions. Reframe now attaches to such a host only for the sessions it runs (shown, typed into and ended as
  before) and starts the current host for new and resumed sessions. Once the older host runs none of the open sessions
  it is let go, and it exits by itself. The "Restart terminal host" action is gone.
- **The shell's log tells which terminal hosts it attached to**, and when the quota could not be read.

The PTY host protocol, the profile and `state.json` are unchanged.
