# ClaudeGPT Reframe 0.11.0-claudegpt.39

- **Thread properties.** A thread's context menu (its list entry, or its tile header) has a new "Properties…" item.
  It shows the name, Reframe's session ID, Claude's session ID, the folder, the model provider and launch options
  (model, effort, permission mode, worktree, added folders), when the thread was created and last active, and its
  state. A running thread also shows its process ID, the PTY host that runs it, and what it uses now (CPU, GPU, RAM
  and its busiest processes). The disk usage lists the thread's files in Claude Code's home: the transcript,
  subagents and tool results, file history, session environment, tasks, todos and debug log, each with its size and
  place, plus the total. These are measured in the background when the dialog opens. Values can be selected, and
  "Copy all" copies the whole sheet.

The PTY host protocol, the profile and `state.json` are unchanged.
