# 0.11.0-claudegpt.72

- `close_thread` takes several threads at once (`names`): they are closed in turn, the threads the caller opened are archived or deleted together in one quiet batch (no popup), and the caller gets one message with the outcome of all of them, including which names could not be closed and why. Threads the caller did not open still ask you once, in a single dialog.
- Subagents now nest under their opener in the Projects section too, even when they run in another folder (they are listed in the opener's project, not their own). Before, only Recents nested them, because a worker in another folder never shared a list with its opener.
- The subagent toggle is now a visible `▾ 3 agents` / `▸ 3 agents` button on the opener's row (click to collapse or expand).
