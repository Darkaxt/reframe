# ClaudeGPT Reframe 0.10.1-claudegpt.20

- The PTY host now serves the session list's past sessions, Claude Code's session titles and the watching of the
  transcripts (a `transcripts` service added to the host protocol without changing its version). The host keeps
  what it read across Reframe restarts and updates, so the list does not read every transcript again after one.
  - The Rust host reads them with a new library (`rust/reframe-transcripts`) and is told of changes by Windows
    instead of looking; the Node host serves the same with Reframe's own code. Both give the same answers.
  - A host from an older Reframe (taken over in an update) does not offer it: Reframe then reads the transcripts
    itself, as before. Sessions in WSL are still read by Reframe itself.

Windows x64 portable release; unsigned.
