# 0.11.0-claudegpt.134

Diagnostics for the shell's unresponsive moments.

- The UI watchdog now logs, for each wait: how long the UI thread actually ran during it (busy or idle), and whether a Normal-priority callback got through while the Input-priority one waited.
- A long stall gets up to three stack samples (at 5, 10 and 20 seconds).
- After 2 seconds without an answer, the watchdog posts the dispatcher's "process the queue" message again. If a lost message is the cause, this ends the stall, and the log says when it was posted.
