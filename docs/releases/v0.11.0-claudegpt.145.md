# 0.11.0-claudegpt.145

Each terminal tile's header shows the thread's model and reasoning effort, such as "Opus 5.5 · high effort".

- Claude and ChatGPT-route threads show what the running session reports in its status line, so a change made inside the session (such as /effort) shows up too. Until the first report, and for Gemini threads, the header shows the model and effort the thread was launched with. The tooltip says which one it is.
- Low effort is shown in the warning colour.
- When a session's process ends, the header goes back to the launch choice until the next process reports.
