# 0.11.0-claudegpt.117

## Quota

- The quota at the foot of the session list is read through LLM Coordinator's supported read-only command
  (`coordinator-client usage quota`) instead of its internal executable, whose private interface had stopped answering
  ("Calling chat identity is unavailable") since 2026-11-14. Its times in seconds are read; a window not reported since
  it reset is left out (unknown, not full).

## Scheduled tasks

- Two runs due together for one thread no longer both type into it: after a run is typed, the thread takes the next one
  only once it was seen busy and is idle again (or after a minute).
- A run that could not be delivered no longer uses up one of the task's runs (COUNT).
- The wake-up task left at quit is never set less than 15 minutes ahead: a run already due no longer starts Reframe again
  right after you quit it.
