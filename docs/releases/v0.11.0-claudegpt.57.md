# ClaudeGPT Reframe 0.11.0-claudegpt.57

- **Fixes Reframe crashing after a scheduled task ran.** When a task's run was taken, its `runs.json` was written with an empty (null) result time, and reading that back on the scheduler's next tick threw, ending the whole app; every launch then crashed within seconds. Empty or malformed values now read as "none", and a scheduler tick that trips on anything is logged (`tasks: tick failed`) instead of closing Reframe.
