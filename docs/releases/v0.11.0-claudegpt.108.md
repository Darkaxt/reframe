# 0.11.0-claudegpt.108

A thread keeps the model it runs, and a window keeps its selected thread.

- **No more silent Sonnet.** A thread without a stored model started with the spawn plan's hardcoded `sonnet`. The shell now passes the provider's saved default (the last model used for Anthropic, e.g. `opus`) and the plan falls back to Sonnet only when there is none.
- **A /model change sticks.** Every 15 s the shell reads the model the running threads' transcripts last used (subagent messages left out) and updates the thread's record when it differs, so a `/model` typed in the terminal or the Chat view's model chip survives the next resume. An alias such as `opus` is kept while the session runs any version of it, and a model of the other provider is ignored.
- **The selected thread survives a restart.** A single window's selected thread is saved with the window and shown again after a restart; the sidebar's highlight follows the thread a single window shows.
- Tests: `ModelSyncTests`.
