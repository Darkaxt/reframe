# 0.11.0-claudegpt.153

- New thread tool `read_thread {name, turns=10, provider?}`: a thread can see what another has been doing. A supervisor no longer has to guess from git status and file times. Reframe types back the last turns of that thread: what it was asked, what it answered, and the tools it ran with a short result, each turn with its time. It also gives the thread's provider, model, status (idle, busy, ended), folder and the path of its full transcript. Long answers go through a file in the messages folder, like long messages do.
- Works for Claude, ChatGPT-route and Gemini (agy) threads, reading the end of the transcript with the Chat view's parser. Several threads of one name are each shown, up to 3; `provider`, or the id in brackets after the name, picks one.
- Threads get the tool when they start under this host.
