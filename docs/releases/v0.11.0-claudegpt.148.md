# 0.11.0-claudegpt.148

Fixes a regression in .147: renaming a thread in the sidebar no longer types /rename into it again and again.

- .147 counts a typed-in message as delivered only once the thread turns busy. Slash commands such as /rename and /model run inside Claude Code and never make the thread busy, so each one counted as not delivered and the rename was typed again at every check. Slash commands are now sent without that wait, as before .147.
