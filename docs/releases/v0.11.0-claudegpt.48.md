# ClaudeGPT Reframe 0.11.0-claudegpt.48

- **Takeover keeps how the session was started.** Taking over a Claude from another terminal (dropping its window on
  Reframe, or Take over… in the list) used to adopt it with no launch options, so it resumed on the default provider
  (OpenAI) with the default permission mode. Reframe now reads the original's executable and command line before
  ending it (query-only access) and resumes it with the same provider (a client under
  `D:\Tools\Reframe\clients\<provider>`, or Anthropic's address in its `--settings`), model, effort and permission mode
  (`--dangerously-skip-permissions` becomes bypassPermissions). main.log records what was read, without the command
  line.
- **Permission mode for existing threads.** The list and tile menus of Reframe's threads have Permission mode (Default
  or one of Claude Code's modes, bypassPermissions included). It applies when the thread next starts, so it can be
  changed while the thread runs.
- **Threads running in another terminal show as detached.** A thread of Reframe's resumed in another terminal showed
  the stop icon next to "Running", and Claudes found running outside Reframe a green ▶; both now show an arrow leaving
  a box (accent colour), "Running in another terminal".
- **Minimize beside the close button.** The tile header's Collapse to the side bar button moved from the far left to
  beside the ×, as a window has them. Fill the window stays in the tiled view and is hidden in Single window view,
  where the toolbar's Tiled view goes back to the tiles.

The profile and `state.json` format are unchanged.
