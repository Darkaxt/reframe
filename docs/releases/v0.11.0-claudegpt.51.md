# ClaudeGPT Reframe 0.11.0-claudegpt.51

- **Thread names reach Claude Code.** A thread renamed in Reframe kept the name Claude Code was started with (or none, so that Claude Code showed an automatic `<folder>-<code>` name in its session list and in the records of tools that read it). Now a running thread renamed here is sent `/rename <name>` as soon as it is idle, and a thread that is not running starts with its new name next time. Threads renamed before this release are told their name the same way after Reframe starts.

The profile and `state.json` format are unchanged.
