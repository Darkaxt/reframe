# ClaudeGPT Reframe 0.10.1-claudegpt.30

**Session start through the shared spawn plan.** Reframe now works out what it spawns for a session (claude's
command line, environment, hook settings file and the record changes of a fresh start) with the same spawn-plan code
the PTY hosts use, so a new, resumed or freshly restarted session starts the same way whichever host is attached.
Nothing changes in how sessions behave: the plans are held to shared fixtures that both the TypeScript and the Rust
implementation must match.

- **Rust PTY host: `launch` service version 2.** `launch.spawnPlan` returns the plan for a session without starting,
  writing or asking anything.
- **Rust PTY host: `overview` service version 1.** An activity index of the Claude Code transcripts (prompts, turns,
  active minutes per day, streaks, most active threads, provider/model/tool breakdown, monthly timeline), cached in
  the profile and built in the background while no session is busy. Reframe itself does not show it yet.

The native Windows shell (WPF) work in the repository is not part of this release.

Windows x64 portable release; unsigned.
