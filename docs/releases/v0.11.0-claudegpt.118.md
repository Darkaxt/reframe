# 0.11.0-claudegpt.118

## Terminal crash when many threads open and close

- Reframe could end with an access violation in the terminal control (`TerminalTriggerResizeWithDimension`) when a
  thread's terminal was resized while its native terminal was not built yet or already destroyed; it happened twice
  while a manager thread deleted several worker threads and opened new ones within seconds. The terminal control
  (Reframe.Terminal.Wpf 1.25.3131-reframe.4) now refuses such resizes, and the shell skips a session's snapshot resize
  when the tile's terminal window has no handle.
