# ClaudeGPT Reframe 0.11.0-claudegpt.53

- **"Use GPU acceleration" applies again.** Since the move to the native shell the setting was saved but not used, so Reframe always drew with the graphics card. Now, with the setting off (the default), the window and the terminals draw in software: WPF's software rendering, and the terminals' renderer with Windows Terminal's "Use software rendering" (Direct3D's WARP rasterizer, on the processor). With the setting on, both use the graphics card. A change applies after Reframe restarts. The terminal control package is now `1.25.3131-reframe.3`.

The profile and `state.json` format are unchanged.
