# 0.11.0-claudegpt.114

The Chat view loads lazily and redraws only what changed.

- **Lazy loading.** A thread's Chat view starts with the end of its transcript (the last 512 KB, from a whole line). Scrolling to the top, or "Show earlier messages" there, loads 1 MB more off the UI thread and keeps the view where it was (up to 64 MB).
- **No full redraw every second.** Each turn is drawn once and kept while it does not change; a working thread redraws only its last turn. A selection or an open fold in earlier turns is no longer lost while the thread works.
- A transcript rewritten (compaction) starts again from its end.
- Tests: `TranscriptReader.ReadRange` (whole lines only).
