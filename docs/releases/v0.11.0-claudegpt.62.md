# ClaudeGPT Reframe 0.11.0-claudegpt.62

- **Your typing no longer mixes into a message Reframe types into a thread.** A wake-up, a scheduled task, a message to the threads from the top bar and a monitor warning are typed into the thread's terminal (a paste, then Enter). Keys you typed into that same terminal meanwhile went in between and ended up inside the message. While Reframe is typing, the keys you type into that thread now wait and follow the message in order, once it is in. Other threads are not held.
- **A thread opened by another thread or a task is not drawn.** It is added to the window collapsed (in the strip of collapsed sessions) and runs there, so no tile appears, the layout does not move and the focus stays where it was. Expand it from the strip to look at it.
