# ClaudeGPT Reframe 0.10.0-claudegpt.3

Selecting several chats now exposes Archive selected, Delete selected, Model provider and Change model from their context menu or the Selected chat actions button. Archive/delete asks once for the batch. Each chat receives a fresh exact transaction, preserving shared indexes and unselected histories. Active/unavailable chats are skipped, independent items continue after a failure, and the window shows completed/skipped/failed results without retrying failed items.

Change model explicitly selects the target provider and exact model ID (blank uses its default), preserving conversation history. The chosen provider/model settings survive restart. It starts no turn and does not force compaction, alter global model/effort/permission settings or switch providers on refusal.

The native executable accepts profile-scoped `--quit`, including while startup finishes. It follows ordinary shutdown and waits existing history work. With no owning instance it opens no GUI. The managed installation includes a hash-bound stop helper, exposed by `active.json` as `stopScript`, that refuses active maintenance stops and observes exact owned process exits without a kill fallback or arbitrary deadline.

Windows verification covers fictional shared-index archive/restore/delete, one batch confirmation/cancellation, active skips, mutation-failure continuation, persisted model/resume arguments, native quit/profile isolation and the shipped stop helper. Packaged runtime bytes match the verified build; helper/backend bytes match reviewed source. Existing distinct ChatGPT/Anthropic executables, subscription/proxy routing, provider settings, native history safeguards, folder tree and rollback remain preserved. The portable release is unsigned.
