# ClaudeGPT Reframe 0.11.0-claudegpt.66

- **Stop, start and restart the proxy from its row.** The proxy status row at the foot of the session list now has a Restart button and a Stop button (Start while the proxy is offline). They use the proxy's own supervisor only: Stop signals its named stop event (as `stop-proxy.ps1` does) and waits, bounded, for the supervisor to exit; Start runs the proxy's own `start-hidden.vbs` hidden. No process is killed, and a proxy no supervisor runs (started by hand) is left alone with a message. While ChatGPT threads run, Stop and Restart ask first. A toast and a `proxy:` line in main.log say how it went. The buttons show only when the proxy's supervisor and launcher are installed.
