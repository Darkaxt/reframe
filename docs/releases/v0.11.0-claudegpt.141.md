# 0.11.0-claudegpt.141

Threads with work still running in the background now say what it is.

- When a Claude thread ends its turn while a command it started keeps running (a long Python script, a build, `gh run watch`), its tile header and its sidebar row now show what runs and for how long, for example "Background: python gemini_image.py · 14 min". A build started through the Coordinator shows its task name. The text also appears in the status mark's tooltip, updates every 20 seconds and disappears when the work ends. Reframe reads this only while some thread is in the background, and never on the UI thread.
- The background mark (two bars) is now drawn at full strength instead of dimmed, so it is noticeable at a glance.
