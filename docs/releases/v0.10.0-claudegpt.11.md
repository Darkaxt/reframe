# ClaudeGPT Reframe 0.10.0-claudegpt.11

- The toolbar's one-off "Tile" button is replaced by a "Single window / Tiled view" switch (Ctrl+Shift+G
  toggles it), remembered per window. Windows from earlier versions start in the tiled view.
  - Tiled view keeps the active project's visible sessions in the even grid: it is arranged again whenever a
    session or group is added, closed, collapsed, expanded or restored, or the project changes. Resizing and
    reordering by drag still work until the next such change.
  - Single window shows one session filling the window: the selected one (sidebar or notification click,
    Ctrl+1…9, a new session). Ctrl+Tab / Ctrl+Shift+Tab and Ctrl+Shift+arrows go through the project's sessions;
    when the shown one closes, the next one is shown.
  - Ctrl+Shift+Z (fill the window with one tile) still works in the tiled view.
- The toolbar's "Workspaces" button is removed: the project view and the view switch replace it. Saved
  workspaces are kept and still open from the tray menu; the toolbar shows the window's workspace name.

Windows x64 portable release; unsigned.
