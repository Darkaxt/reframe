# 0.11.0-claudegpt.106

Settings is split into tabs (General, Claude, Profiles, Advanced, Threads) in a wider window, and each provider (Anthropic, ChatGPT) gets a profile manager: named launch presets (model, effort, permission mode, extra folders) that you can create, edit, duplicate, delete and make the default. New session has a Profile select that fills the form. Not included: a per-profile claude binary or command-line arguments.
