# 0.11.0-claudegpt.137

A shorter unresponsive minute after each start.

- The published shell is precompiled (ReadyToRun). Previously every start compiled the shell, the Windows SDK projection and the terminal control on the UI thread, and the windows stalled for 1 to 11 seconds at a time for most of the first minute.
- The tray icon is added, updated and removed off the UI thread. Shell_NotifyIcon waits for Explorer, which held the UI thread at startup.
