# 0.11.0-claudegpt.82

- `close_thread` copes with threads of the same name. Two Skyrim workers opened under one name could never be closed ("more than one thread has that name"). Now: when every thread of that name was opened by the asker, all of them are ended/archived/deleted; otherwise the reply lists them with their ids in brackets, and a name with that suffix (`name [0e0e25]`, as the thread list shows it) picks the one meant.
