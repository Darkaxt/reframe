# 0.11.0-claudegpt.130

## Threads message each other with wake_thread, whatever their provider

- A thread told the user it could not reach a Gemini thread: wake_thread read as a tool for ended threads only, and
  threads were told to answer with SendMessage, which only Claude sessions have. wake_thread is described now as what
  it does: a message to any Reframe thread by name (Claude, ChatGPT or Gemini, running or ended), typed in once it is
  idle. The Reframe tools' guide says so to every thread (also without a tasks folder).
- A message delivered that way starts "[message from the Reframe thread "…"; answer it with wake_thread to "…"]",
  and a thread opened by another is told to answer with wake_thread too.
