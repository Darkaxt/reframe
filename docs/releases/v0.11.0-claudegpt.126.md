# 0.11.0-claudegpt.126

## Terminals that are not shown stop drawing

- Every thread's terminal kept drawing while it was not shown (the other threads of a single window, docked tiles, a
  hidden window): each had its own render thread drawing every output and every cursor blink, in software by default
  ("Use GPU acceleration" off). With many threads open, that meant constant CPU use and input lag, and some terminals
  flickered.
- The terminal control (Reframe.Terminal.Wpf 1.25.3131-reframe.5) can now pause a terminal's drawing
  (`TerminalSetPainting`). The shell pauses a terminal while it is not shown and resumes it, redrawing everything, when
  it is shown again. Output still goes into the terminal's buffer while it is paused.
