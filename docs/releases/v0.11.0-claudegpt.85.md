# 0.11.0-claudegpt.85

- Reframe restarts itself into a newly installed release. It checks the deploy's `active.json` every 30 seconds; when a different release is installed it waits until you are not in a Reframe window, then starts the new one and quits. Sessions keep running in their host and the new shell attaches to them.
- Settings: "Restart into new releases automatically" (on by default). Off: a notification says an update is installed and you restart yourself.
- The Chat view and the session list already refresh on their own (the Chat view re-reads its transcript every second while shown).
