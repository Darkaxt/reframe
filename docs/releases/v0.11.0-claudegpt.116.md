# 0.11.0-claudegpt.116

## Chat view

- A session waiting for you (a permission prompt or a question) shows a bar above the message box: "The session is
  waiting for you in the terminal", with **Open the terminal** (this tile only; the Chat / Terminal choice stays).
- The Stop button follows the session's status (busy), so it stays during long work instead of going after ten minutes
  without a write; the transcript is only used when there is no status.
- Thoughts read like the answers (no coloured edge).
- A scheduled task's prompt and another session's message are bubbles on the right, folded to their title, with
  "Sent by scheduled task" / "Sent by <session>" under them. Background-task notices stay one muted line.
- Markdown: tables (header row shaded, thin borders) and links (`[text](https://…)` and bare web addresses) that open in
  the browser.
