# ClaudeGPT Reframe 0.11.0-claudegpt.55

- **Threads can wake ended threads.** A new thread tool, `wake_thread(name, message)`, lets a thread resume another thread that has ended (its tile closed or its Claude stopped) by the name Reframe shows, and give it a message. Reframe resumes the thread's own conversation, waits until it is idle and types the message in, telling it which thread woke it so that it can answer with SendMessage. A thread that still runs gets the message once it is idle. If no thread, or more than one, has that name, the asking thread is told in a message. Together with `open_thread` (new threads) and scheduled tasks, threads can now start, wake and talk to each other.
- **Close ended threads after N hours.** A new setting, off by default (choices: 1, 3, 6, 12 or 24 hours). A thread whose Claude ended that long ago and whose tile is still open is closed as the tile's × does: the tile goes, the thread stays in the list and can be resumed, or woken by another thread. Running threads, threads starting, threads a task or a wake-up is about to resume, and threads whose start failed are never closed. A thread found ended counts from its last use.

The task tools are in the Rust host, so threads get this tool after the host starts again. The profile and `state.json` gains an optional `closeEndedAfterHours` preference, written only when set.
