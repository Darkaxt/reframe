# 0.11.0-claudegpt.129

## Models are picked, not typed, in Settings

- "Model for new sessions" (each provider's defaults, and each profile) was a text field: a typo or a retired model
  was saved as it was. It is a list of the provider's models now, with Default first, the same as New session's. A model
  set before that is not in the list shows as "<model> (not offered)" until another is picked; nothing is changed
  until then.
