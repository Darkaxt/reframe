# ClaudeGPT Reframe 0.10.0-claudegpt.4

Fix slow selected-chat deletion on Windows. Read-only planning no longer repeats
activity checks; the exact-retirement helper owns one fresh native process check
immediately before mutation. Preserve running chats, protected identities,
shared-index rows, exact snapshots and per-item failure/skip reporting. Archive,
delete and provider/model batches retain one confirmation where applicable.

The managed installation binds thread-cleanup0.1.1 and its pinned psutil7.2.2
native reader. Missing/unreadable process evidence preserves histories.
No user chat is deleted for qualification. The Windows portable release is unsigned.

New session now exposes Effort, inherits a saved default from Reframe Settings,
and retains explicit effort on resume. Projects are organized under separate
ChatGPT and Claude roots; the same project folder can belong to both without
merging chat lists. Every project workspace has a + for a prefilled new session.
Global creation defaults to Documents/ChatGPT and Documents/Anthropic respectively.
Existing folders, histories, pins and recents remain intact.
