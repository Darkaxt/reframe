# 0.11.0-claudegpt.115

## Defaults that threads follow

- Settings shows the defaults of each provider ("New Anthropic threads", "New ChatGPT threads": model, effort, permission
  mode), starting from the values new threads used until now. Starting a session no longer replaces them with that
  session's choices; New session's first profile entry is "Default settings".
- A thread remembers which choices it took from the defaults (New session with the defaults left as they were,
  `open_thread` without a model or effort, a scheduled task's new thread). When a default changes in Settings (or a
  profile is made the default), those threads take the new value at their next start.
- A choice changed for one thread stays: the Change model dialog, the permission menu and a `/model` typed in the
  thread end following for that choice only. A thread still running the model it started with before the defaults
  changed is not taken for a `/model`.
- Threads made before this release keep their own choices.
