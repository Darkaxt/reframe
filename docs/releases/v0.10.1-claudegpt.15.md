# ClaudeGPT Reframe 0.10.1-claudegpt.15

- New setting "Look for Claude Code in WSL" (Settings, Windows only), off by default, also for existing state files.
  - Off: the session list no longer asks WSL anything in the background. Before, it ran `\wsl.exe -l --running` every
    20-60 s and a login shell in every running distribution without Claude Code every 30 s, which kept the WSL VM
    from shutting down when idle. Sessions from WSL distributions, and the note about known stopped ones, are not
    listed.
  - Opening, resuming or taking over a session in a `\\wsl$` / `\\wsl.localhost` folder, and handing over a WSL
    terminal window dragged onto Reframe, still ask the distribution on demand, as before.
  - On: the session list looks in running distributions as before. Turning it on looks at once; turning it off
    drops WSL sessions from the list.
- A running distribution without Claude Code is asked only once, until it is seen not running, instead of every 30 s.

Windows x64 portable release; unsigned.
