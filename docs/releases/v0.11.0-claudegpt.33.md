# ClaudeGPT Reframe 0.11.0-claudegpt.33

A fix release for the native WPF shell.

- **Arrow keys and Tab reach the session again.** The terminal is a native window inside the shell, and WPF's
  keyboard navigation took the arrows and Tab first (moving the focus instead), so the cursor could not move and
  Claude Code's multiple-choice prompts could not be answered with the arrows. They now go straight to the terminal;
  Shift+Tab cycles Claude Code's modes again. Window shortcuts (Ctrl+Shift+arrows, Ctrl+Tab) are unchanged.
- **Starting Reframe twice keeps the launch record.** A second start while Reframe is already running only hands off
  to it; `start-managed.ps1` no longer overwrites the running instance's launch receipt with that short-lived process.

The PTY host protocol, the profile and `state.json` are unchanged.
