# ClaudeGPT Reframe 0.10.0-claudegpt.6

Archive and delete of selected chats run in one batch: two Python processes and
one live-client census per confirmation instead of several per chat (ten small
chats: about 10 s instead of 100 s). Startup no longer re-hashes the history
backend, and restoring an archived chat no longer crashes when it is still active.

The session list can be resized (200–640 px; double-click the edge for the
default, arrow keys step it). New session takes a first message and additional
folders (`--add-dir`), and remembers model, effort, permission mode and folders
per provider. Window, taskbar and installer use the tray artwork.

Fixes: archive roots on C: are refused however the drive is written; tiles whose
Claude transcript is gone can be closed from one menu; quitting never waits on an
open archive/delete confirmation; derived project groups are no longer saved in
state.json.

Deployment: only clients coupled to the installation (the app, what it started,
and clients running from or configured into its folder) must be idle for an
activation or restore. A Claude CLI installed elsewhere may keep running.
Windows x64 portable release; unsigned.
