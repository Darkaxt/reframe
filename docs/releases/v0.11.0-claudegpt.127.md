# 0.11.0-claudegpt.127

## Less drawing while threads work

- The pulsing status icons (busy, waiting and starting threads, and a running task's clock) kept WPF drawing the window
  60 times a second for as long as any of them pulsed, in software when GPU acceleration is off, on the UI thread and
  WPF's render thread. They now pulse at 15 frames a second, and only while they are shown.
- The sidebar was built again from scratch every time the list was refreshed: every five seconds, and every two while
  threads were writing their transcripts. It is now built again only when something it shows has changed (a label,
  status, stamp, order, task clock…).
- A minimised window's terminals stop drawing too, as hidden ones have since .126.
