# ClaudeGPT Reframe 0.10.1-claudegpt.17

- New setting "Use GPU acceleration", off by default (also for existing profiles). Reframe draws terminals, which
  need no graphics card, and NVIDIA driver resets (TDRs) were seen in bursts while it used one.
  - Off: Chromium runs without hardware acceleration and terminals draw with xterm's DOM renderer from the start
    (WebGL is not tried).
  - On: as before, WebGL terminals with the recovery from GPU loss of 0.10.1-claudegpt.14.
  - A change takes effect after restarting Reframe; Settings says so until then. The log says at startup whether
    hardware acceleration is on, to compare with the times of any later driver resets.

Windows x64 portable release; unsigned.
