# ClaudeGPT Reframe 0.11.0-claudegpt.47

- **Thread status as media-player icons.** The status dot in the tile headers, the session list and the dock is now
  an icon, in the same colours as before: running a play triangle (pulsing), waiting on a background command a pause,
  needing you a question mark (yellow, pulsing), ready for a prompt a check (green), starting an outlined play (grey,
  pulsing), ended a stop square (grey), failed to start an exclamation mark (red). Hovering it names the status.
- **Only folders with a running thread start open.** A fresh start used to open every folder workspace it had saved
  as open; now the session list opens those with a thread running (and a folder whose first thread starts later, once),
  and leaves the others closed. Opening and closing them by hand works as before.

The profile and `state.json` are unchanged.
