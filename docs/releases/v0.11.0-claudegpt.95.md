# 0.11.0-claudegpt.95

- Fork a thread from a point of its conversation: in the Chat view, right-click one of your messages ("Fork a new thread from before this message") or an answer ("Fork a new thread from here"). Reframe copies the conversation up to that point into a new thread (the old one is untouched, and a tool call without its result is left out) and resumes it next to the old one, so a thread stuck on a rejection can be continued with another approach.
