# ClaudeGPT Reframe 0.11.0-claudegpt.60

- **`wake_thread` takes a thread's own name before a folder name.** A thread with no name is shown by its folder's name, so an older "Skyrim" folder thread and a thread named Skyrim were both "Skyrim" and the wake was refused as ambiguous.
