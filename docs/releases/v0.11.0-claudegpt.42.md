# ClaudeGPT Reframe 0.11.0-claudegpt.42

- **The tray icon stays shown after updates.** Windows 11 remembers "show this icon on the taskbar" per executable
  path, and each release runs from its own version folder, so after every update the icon started hidden in the
  overflow (^) again. A release now takes the choice the user made for the newest earlier release, unless one was
  already made for it, and removes Windows' records of releases that are no longer installed.

The PTY host protocol, the profile and `state.json` are unchanged.
