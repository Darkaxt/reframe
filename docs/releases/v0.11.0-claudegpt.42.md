# ClaudeGPT Reframe 0.11.0-claudegpt.42

- **The tray icon stays shown after updates.** Windows 11 remembers "show this icon on the taskbar" per executable
  path, and each release runs from its own version folder, so after every update the icon started hidden in the
  overflow (^) again. A release now takes the choice the user made for the newest earlier release, unless one was
  already made for it, and removes Windows' records of releases that are no longer installed.
- **The tray icon comes back after Explorer restarts.** The icon's window was a message-only one, which gets no
  broadcasts, so it missed Windows' "taskbar created" message and the icon stayed gone until Reframe restarted. It is
  now a hidden tool window (as Electron's), and the icon is put back.
- **The Claude quota is back at the foot of the session list.** It comes from the status line Claude Code gives
  reframe's sessions (their 5-hour and 7-day limits), which the WPF shell did not read at all, and which was captured
  only for users without a status line of their own. Now the PTY host relays it: it hands the quota to reframe, then
  runs the user's own status line command with the same input, so the user's status line stays as it is. Sessions
  started or resumed under this release's host show it.
- **Terminals fill their tile again.** A thread could draw in only part of its tile (in a single window, a quarter)
  after it was resized while hidden or at another display scale. Each terminal is now fitted to its tile when it is
  shown, when the tile changes, and when the window moves to a display of another scale; a hidden one no longer
  resizes its session.

The PTY host's `launch` service is version 3 (the status line relay); the profile and `state.json` are unchanged.
