# ClaudeGPT Reframe 0.11.0-claudegpt.56

- **An update reaches the pty host, not only the window.** Reframe used to attach to whichever pty host was still running, so after an update new threads kept getting the old host's build, and with it the old thread tools (no `wake_thread`, no `effort` for `open_thread`). Now a host that runs another build than the one Reframe ships keeps its sessions, but a current host is started for new ones. The old host ends by itself once its sessions end. If no current host can be started, or another client is attached, the old host is used as before. Nothing is ended or restarted for this.
- Threads that were already open keep the old tools until they are reopened (their Claude process holds the old tool server).
