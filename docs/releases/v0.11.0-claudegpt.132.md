# 0.11.0-claudegpt.132

## main.log tells when the windows stop responding

- Reframe at times did not respond for a while, with little CPU use on average, so nothing showed what held it. A
  watchdog thread now asks the UI thread every half second for an Input-priority callback (where keys and clicks
  wait). A wait of 400 ms or more is logged as `ui: did not respond for N ms`, with what the UI thread was doing (the
  session list, drawing the sidebar, the chat view's transcript, terminal output or a snapshot), how many terminal
  outputs waited on the dispatcher, and whether a full garbage collection ran; a wait of 5 s is logged while it lasts.
- Nothing else changes; it costs one callback every half second.
