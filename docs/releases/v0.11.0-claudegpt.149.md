# 0.11.0-claudegpt.149

Messages reach threads that still run in an older host.

- After an update, a thread started by an earlier Reframe keeps running in the host that started it. Everything Reframe typed into such a thread (wake_thread messages, scheduled task runs, /rename, monitor warnings) was sent to the current host instead, which does not have that thread and ignored it. Nothing arrived, and the thread stayed idle. That is why the messages to Navic were lost since the 22nd. Reframe now types into the host that runs the thread, as its tile already did.
