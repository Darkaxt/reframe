# ClaudeGPT Reframe 0.11.0-claudegpt.43

- **Terminals fill their tile again, also after switching threads.** When a thread's terminal is attached, it first
  takes the size of the session's last screen. That step also put a margin around the terminal window to keep it at
  that size, and nothing took the margin off. So a session last shown in a quarter tile stayed a quarter of its
  tile in a single window, and the window's own resizes kept the session at that size. The margin is now cleared
  once the screen is drawn, and again whenever a terminal is fitted to its tile.
- **A single window stays empty after the shown thread closes.** When the thread ended or was closed through the
  shell (rather than by a layout change in the window), the window showed another running thread instead of
  "Choose a session from the list." It now stays empty whichever way the thread left.

No protocol, profile or `state.json` changes.
