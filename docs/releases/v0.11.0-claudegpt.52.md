# ClaudeGPT Reframe 0.11.0-claudegpt.52

- **A clock on threads with scheduled tasks.** As in Codex, a thread with one or more scheduled tasks shows a clock after its name in the session list and in its tile's header. The tooltip tells how many tasks it has.
- **The thread's tasks in a floating panel.** A click on the clock opens a panel under it with that thread's tasks, their schedule, next run and last result. Each task can be run now, paused or resumed, edited or deleted there. The panel closes when it loses the focus, or when its last task is deleted. The top bar's Scheduled tasks button still lists every task and imports from Codex.

The profile and `state.json` format are unchanged.
