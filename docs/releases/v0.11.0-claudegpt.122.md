# 0.11.0-claudegpt.122

## New session: pick the model

- The model is picked beside the effort, from the provider's models by name, instead of a text box under Advanced.
  A model set elsewhere (Settings, a profile) is listed too. The dialog is titled "New session".
- Gemini models are families (Gemini 4 Neon, Hydrogen, Argon, 3.8 Flash); the effort picks agy's variant
  (low, medium, high, xhigh; max is the highest, which is high for Argon and Flash). The chat view's model chip does the same.
  A default saved as an agy id with its effort (.120) shows as its family.
