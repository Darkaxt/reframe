# ClaudeGPT Reframe 0.11.0-claudegpt.46

- **`open_thread` always names the provider.** A thread that opens another thread must now say which models it runs
  on, `openai` or `claude`: the tool asks for it and refuses a request without it, and reframe opens nothing without
  one, so the thread chooses deliberately rather than getting OpenAI by default.
- **The Overview shows again over open threads.** Its pane was drawn, but the terminals (windows of their own, which
  WPF cannot draw over) stayed on top of it, so the thread underneath showed through. The layout is now hidden while
  the Overview is open, and its terminals are fitted again when it closes.

The PTY host's `launch` service stays at version 5; the profile and `state.json` are unchanged.
