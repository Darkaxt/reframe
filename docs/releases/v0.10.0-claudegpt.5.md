# ClaudeGPT Reframe 0.10.0-claudegpt.5

Projects now groups chats by their final working-folder name in one tree, across
parent paths and providers. ChatGPT/Android and Anthropic/Android appear together
under Android; provider icons remain on chats. Actual working directories,
histories, provider selections, effort and permission settings stay intact.

Project paging/search includes every matching folder. Existing full-path and
provider-scoped expansion state migrates to the merged branch. Each project keeps
its + control; the session dialog retains known folder/provider locations.
Global new-session storage roots remain Documents/ChatGPT and Documents/Anthropic.

The included `start-anthropic-session.ps1` launches the dedicated native subscription
CLI directly from a terminal, applying complete routing/model-alias isolation for
all models and forwarding explicit model, effort and permission flags unchanged.
The launcher was verified with a benign native Opus subscription request.

Includes the existing one-confirmation bulk actions, native quit channel, effort
defaults and fast native offline-chat checks. No forced compaction, account changes
or automatic provider switching. Windows x64 portable release; unsigned.
