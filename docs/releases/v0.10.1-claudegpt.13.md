# ClaudeGPT Reframe 0.10.1-claudegpt.13

- Saved workspaces are gone. Projects are the folders sessions run in (as in Codex and Claude), so the old way of
  saving a window under a name is removed end to end: the Workspaces menu and its save, update, rename, delete and
  open actions, the tray's Workspaces submenu, the save/rename dialog, the workspace name in the toolbar, their IPC
  channels and texts, and the "close tiles whose transcript is gone" entry that only that menu offered.
- Folder projects, project activity and the Single/Tiled view are unchanged.
- An existing `state.json` that still holds saved workspaces loads as before; they are dropped and the next save
  writes the file without them.

Windows x64 portable release; unsigned.
