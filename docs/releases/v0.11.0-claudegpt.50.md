# ClaudeGPT Reframe 0.11.0-claudegpt.50

- **Scheduled tasks for threads.** A thread can schedule work for itself when you ask it to, with the new `schedule_task`, `list_tasks`, `update_task` and `delete_task` tools of its Reframe thread tools. A task has a name, a prompt and an iCalendar rule (daily at 9:00, every Monday, every 6 hours, and so on). Tasks are saved in the profile's `tasks` folder in the same `automation.toml` format as Codex automations.
  - When a task is due, Reframe types its prompt into the thread. An idle thread gets it at once. A busy thread gets it when it becomes idle, because a task never interrupts work. An ended thread is resumed first. A task can also start a new chat in the same folder.
  - A run that was missed while Reframe was closed runs once at the next start, and the schedule goes on from there.
  - Failed runs show a notification. A task can ask for a notification after every run.
- **Tasks window.** The new **Scheduled tasks** button in the top bar lists the tasks with their next run and last result. Each one can be run now, paused or resumed, edited or deleted.
- **Import from Codex.** Codex automations whose thread has the same name as a Reframe thread can be imported from the Tasks window. Codex files are only read; pause the Codex copy so that the task does not run twice.
- **Wake up for tasks.** A new setting, off by default, leaves a one-time Windows scheduled task when Reframe quits. It starts Reframe in the tray at the next due run. The task is removed when Reframe starts.

The task tools are in the Rust host, so threads get them after the host starts again. `state.json` gains an optional `wakeForTasks` preference, written only when it is on; the profile format is otherwise unchanged.
