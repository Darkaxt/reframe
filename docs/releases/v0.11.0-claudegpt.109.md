# 0.11.0-claudegpt.109

Tray Reload, a narrow tray menu, and no more stutter from the model sync.

- **Reload in the tray.** Starts the shell again the way its shortcut does: with a managed start it runs the launcher (`REFRAME_APP_LAUNCHER`, through wscript) once this shell has gone, so the hash checks, client adoption and the installed release all apply; otherwise it restarts into the installed update, or itself. Sessions keep running in their host. A hidden helper (`reframe.exe --relaunch <launcher> --after-pid <pid>`) waits for the old shell and starts the launcher; it never opens a window.
- **Short window entries.** Each thread name in a tray window entry is cut to 24 characters and the names together to 60, so long thread names no longer make the menu screen-wide.
- **Model sync without stutter.** .108 read the tail (512 KB) of every running thread's transcript every 15 s, which stuttered the UI with many busy threads. Now only the thread that just finished a turn is read, its last 64 KB first, and the record is saved without redrawing the lists. Saving the selected thread no longer redraws the lists either.
- Tests: tray menu with Reload, and the tray entry length.
