# ClaudeGPT Reframe 0.10.0-claudegpt.9

Fix: starting reframe.exe directly from its release folder (instead of the
"Reframe - ClaudeGPT" shortcut) opened an empty profile and could not find
Claude Code. The installed release now carries `reframe-config.json` with the
fixed profile, runtime folder and the exact path and sha256 of each provider's
CLI. A direct start uses it; the managed launcher's settings still win. Neither
CLI is added to PATH, and a provider whose binary is missing or changed is
refused instead of falling back to PATH or the other provider.
Windows x64 portable release; unsigned.
