# 0.11.0-claudegpt.140

Freezes in .139, and updates that restarted a window in use.

- An installed update no longer restarts Reframe while one of its windows is on screen. Before, a window that was shown but not focused counted as unused, so a window filling most of the monitor was restarted under the user. Now Reframe restarts into an update only when its windows are minimized or closed to the tray, or when nobody has touched the keyboard or mouse for half an hour; otherwise it says an update is installed and waits (the tray's Reload restarts at once).
- Stall diagnostics no longer take a snapshot of the process. In .139 the UI stalls were mostly idle ones (the UI thread waiting for messages, not working), and the watchdog itself stopped for 15 seconds inside one: each stack sample cloned the process (ClrMD's snapshot), which holds the whole process while it copies its address space, including the graphics driver's mappings. Stacks are now read live, without stopping anything, and named by module and offset; JIT-compiled frames by address. ClrMD is no longer shipped.
- The dispatcher hooks added in .139 that named every UI-thread operation are removed: they ran on every operation and named nothing in the stalls that mattered (those happened outside any operation).
