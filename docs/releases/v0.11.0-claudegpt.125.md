# 0.11.0-claudegpt.125

## Missed cron jobs go to their own thread too

- .124 handed a cron job that fired in another thread back to the thread that made it, but not a one-shot job that
  was missed. A session that starts in the folder finds such a job and gets Claude Code's notice of missed jobs ("The
  following one-shot scheduled task was missed…", asking the user whether to run it), with each job's prompt fenced
  inside. The tag is inside the notice, not on its first line, so the notice went through, and the wrong thread asked
  the user about another thread's job.
- Now a notice with another thread's job in it is blocked, and each thread gets the notice with its own jobs only, so
  the question is asked in the thread that made the job. The thread that got the notice gets its own jobs, and any
  untagged ones, back as they were.
