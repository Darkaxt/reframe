# 0.11.0-claudegpt.107

Claude in Chrome and the managed clients, in Settings › Claude.

- **Claude in Chrome per provider.** Two new selects (Anthropic, ClaudeGPT): the CLI's own setting, On (`--chrome`) or Off (`--no-chrome`). A session started or resumed from now on gets the flag from the spawn plan (`launch.chrome`). ClaudeGPT sessions may not offer the tools, because they do not sign in to claude.ai; the setting is there to try it.
- **Managed clients.** Settings › Claude shows the CLI each provider was started with (the launch config's pins, `REFRAME_CLAUDE_BIN` and `REFRAME_ANTHROPIC_CLAUDE_BIN`): version, path, and whether the client adoption record pinned and hash-checked it. The Claude Code path chosen in Settings is only used for a provider with none pinned.
- Tests: `BrowserTests` (settings round trip and patch) and a spawn plan test for `--chrome` / `--no-chrome`.
