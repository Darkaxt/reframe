# ClaudeGPT Reframe 0.11.0-claudegpt.32

A fix release for the native WPF shell (0.11.0-claudegpt.31).

- **Window frame restored.** The main window had no shadow, no border and square corners, so it looked cut off
  against the desktop: the WindowChrome's zero-thickness glass frame turned off Windows' own non-client rendering.
  A 1px glass frame brings the DWM shadow and border back, and the window asks Windows 11 for rounded corners.
- The window title is now `Reframe` (it was `Reframe Shell (experimental)`).

The PTY host protocol, the profile and `state.json` are unchanged; the hot swap from .31 keeps running sessions.
Rollback to Electron works as described in the 0.11.0-claudegpt.31 notes and `docs/wpf-cutover.md`.
