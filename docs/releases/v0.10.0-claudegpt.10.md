# ClaudeGPT Reframe 0.10.0-claudegpt.10

- The window, About dialog and tray are called "Reframe" (the exe, package and profile folder are unchanged).
- Projects are isolated: opening, focusing or clicking a project shows only its sessions and docks the other
  projects' tiles. New "Tile" layout (toolbar, Ctrl+Shift+G) arranges the visible sessions in a near-square grid.
- Sidebar project headers show how many sessions run there and the state that most needs attention
  (waiting, error, busy, idle) as a shape and colour.
- Clicking a notification switches to that session's project.
- Quota panel at the bottom of the sidebar: Claude 5-hour/7-day usage from Claude Code's status line (only when
  you have no status line of your own) and Codex usage from LLM Coordinator, with time until reset.
- Windows title bar is merged into the toolbar (native window buttons overlay).
- Session names: only a name you type is passed to Claude Code as `--name`; otherwise the label follows
  Claude Code's own latest title (custom or AI title), then the folder. Transcripts and state are not rewritten.
- Deployment: `deploy-managed.ps1 -KeepRunning` installs a release while the running one continues
  (status `installed_pending_launch`; the next launch starts it).

Windows x64 portable release; unsigned.
