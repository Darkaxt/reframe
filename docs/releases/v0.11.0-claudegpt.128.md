# 0.11.0-claudegpt.128

## No "Terminal host" setting any more

- Settings still offered Electron's "Terminal host: Node (default) / Rust (experimental)", showing Node. The setting
  did nothing: the WPF shell always runs the Rust host (the Node host went with Electron). It is gone, and so is the
  `ptyHost` key in state.json (an old file's is read and dropped). A session's properties show the host's version and
  process id.

## No "name from folder" preference

- `nameFromFolder`, another Electron preference, was kept in state.json but never used by the shell and not in
  Settings. It is dropped the same way.
